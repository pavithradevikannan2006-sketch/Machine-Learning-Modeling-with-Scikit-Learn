# Machine Learning Modeling with Scikit-Learn

## Overview

This project demonstrates a complete machine learning pipeline using Python and Scikit-learn. It covers both classification and regression tasks, including data preprocessing, feature engineering, model training, evaluation, and interpretation.

The project was developed as part of the Soft Nexis Machine Learning Modeling task.

---

## Objectives

- Build a complete machine learning workflow
- Perform data preprocessing and feature engineering
- Train multiple machine learning models
- Evaluate and compare model performance
- Interpret model results using feature importance

---

## Datasets Used

### 1. Titanic Dataset (Classification)

Objective:
Predict whether a passenger survived based on passenger information.

Target Variable:
- Survived

Features:
- Passenger Class
- Sex
- Age
- Fare
- Family Size
- IsAlone

Models Used:
- Logistic Regression
- Random Forest Classifier

Evaluation Metrics:
- Accuracy
- Precision
- Recall
- F1-Score
- Classification Report

---

### 2. California Housing Dataset (Regression)

Objective:
Predict median house values using housing attributes.

Target Variable:
- Median House Value

Models Used:
- Linear Regression
- Random Forest Regressor

Evaluation Metrics:
- RMSE
- MAE
- R² Score
